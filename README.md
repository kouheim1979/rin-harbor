# リンハーバー DX

リンちゃん専用の、港を舞台にした合成パズルゲームです。

## DX版の主な機能

- 単一HTML構成へ刷新（多重iframeを廃止）
- 外部ライブラリなし / 外部通信なし
- iPhone / Android のブラウザに最適化
- localStorageによる自動保存
- 旧セーブ（v5〜v8）からの自動移行
- 6×6の合成ボード
- ドラッグ合成 / タップ合成
- 1手戻す
- 合成ヒント
- コンボボーナス
- 8件の注文システム / 自動納品
- リン号5段階修理
- 修理アルバム
- 星で進む港の物語
- リン図鑑（5系統×10レベル）
- デイリーミッション / 連続プレイ
- 効果音 / 触覚フィードバック設定
- セーブデータのバックアップ / 復元
- Service Workerによるオフライン起動

## 遊び方

1. 「リンカフェ屋台」や「海辺のかご」をタップして材料を出す
2. 同じアイテムを2つ重ねて合成する
3. 注文に必要なアイテムをそろえて納品する
4. コインでリン号を修理する
5. 星で港の物語を進める
6. 図鑑・デイリーミッションのコンプリートを目指す

## データについて

進行状況はブラウザの `localStorage` に保存されます。
旧版の `rin_harbor_save_v5` 〜 `rin_harbor_save_v8` がある場合、DX版の `rin_harbor_save_v10` へ自動移行します。
