# リンハーバー — Sea Journal / Atelier 4

小学高学年向けの、海の冒険と合成を楽しむゲームです。
公開先: https://kouheim1979.github.io/rin-harbor/

## アイテムの見分け
5系統×10段階と3つの屋台、計53種類をそれぞれ異なるSVGの形で描いています。同じ絵に色枠を足す方式は使いません。例えばケーキ、カップケーキ、パンケーキ、焼き魚、エビ、カニはそれぞれの物の形になります。盤面・注文・図鑑・倉庫は同じ描画定義を使います。

アイテムを1回タップすると名前とLvが表示されます。同じ種類・同じLvの2つが合成できます。選択したアイテムと合成できる相手は点線で表示します。

## つくり方ガイド（20260908-guide1）
注文の絵を押すと、材料を出す屋台・合成の順番・盤面と倉庫の個数を確認できます。「この注文を目標にする」で、画面上部の注文とヒントを合わせます。目標の注文は納品すると解除されます。ガイドの「おまかせに戻す」でも解除できます。

ヒントは、注文に必要な完成品を先に確保してから、残りの材料で合成できる組を案内します。目標を指定しない場合は、盤面の途中段階の材料も考慮して近い注文を選びます。倉庫のアイテムを勝手に取り出したり、納品したりしません。つくり方を見るだけでは、図鑑の発見も増えません。目標指定は今回の画面だけの設定で、既存セーブの形式を変更しません。

## みなとの倉庫
- ゲーム右上の黄色い「倉庫」、下部メニューの「倉庫」、ホームの倉庫カードから開きます。
- 盤面のアイテムを1回タップして「預ける」で保管。倉庫の「取り出す」で1個ずつ盤面へ戻します。
- 屋台は収納できません。倉庫が満杯のときは預けられず、盤面が満杯のときは取り出せません。操作に失敗しても個数は変わりません。
- 預け入れ・取り出しは1手戻せます。
- 最初は12個。リン号の修理1段階につき4個分、プレイヤーレベルが3つ上がるごとに2個分増えます。
- 保管中のアイテムは自動納品に使われません。取り出した直後も自動納品はしません。
- 保管数は自動保存とバックアップの対象です。

倉庫の画面と操作はアプリ本体に組み込まれています。初回アクセスやService Workerが使えないブラウザでも倉庫を開けます。旧版のHTML応答への後付け挿入と、起動後に関数を差し替える方式は廃止しました。

## データ
保存キー `rin_harbor_save_v10` は変更しません。倉庫を含む旧セーブを読み込んでから初回の保存を行います。移行前の控えは `rin_harbor_before_warehouse_v4` に保管します。UI更新でプレイヤーデータを初期化しません。

## 構成
`index.html` / `youth.css` / `item-art.js` / `game.js` / `sw.js` / `assets/art-hd/`。
`release-source/` と `scripts/build_atelier4.py` は旧版から今回の統合版を構築するためのソースです。配信時にビルドは不要です。古い `warehouse.js` と `item-art-levels.js` は無処理の互換ファイルで、現在のHTMLからは読み込みません。

## 画像処理
タイトルと修理イラストは元の1440px画像をOpenCV dnn_superresのFSRCNN x2で再構成したものです。タイトル2880×1620、修理6枚2880×2160。新しく描いたネイティブ4K原画ではありません。アルバム一覧には480×360の軽量サムネイルを使います。
モデルと画像のSHA-256・寸法は `assets/art-hd/manifest.json` に記録しています。
モデル: https://github.com/Saafke/FSRCNN_Tensorflow （Apache-2.0）
OpenCV: https://docs.opencv.org/4.x/d5/d29/tutorial_dnn_superres_upscale_image_single.html
